# 过载余波

> 算力过载，主动猎杀。

《过载余波》是一款竖屏俯视角、几何霓虹风格的短局街机 Roguelite。玩家会在“强大—失控—逃亡—翻盘”的循环中，不断切换猎人与猎物的身份。

## 游戏官网

**[访问《过载余波》官方网站](https://xxxzzzfff2020.github.io/overload-aftershock/)**

官网由本仓库 `docs/` 目录中的静态 HTML、CSS 与媒体资源构成，并通过 GitHub Pages 独立发布。页面包含游戏介绍、核心循环、先行影像、TapTap 扫码入口与 GitHub 源码入口。

## 公开源码

游戏源码和运行所需的原始资源已公开在本仓库根目录：

- `scripts/`：Lua 游戏逻辑、渲染、UI、流程与测试代码。
- `assets/`：游戏使用的图像、音频及资源清单。

项目基于 TapTap Maker / UrhoX 运行。若要在本地继续开发，请新建或使用兼容的 Maker 项目，再将这两个目录复制到项目根目录；引擎会生成本地 `.meta` 文件。

## 隐私与平台配置

为保护发布账号与广告配置，本仓库刻意不包含 `.project/`、`.maker/`、`.maker-mcp/`、构建缓存、测试二维码、存档或会话数据。`app_id`、`developer_id`、小游戏 ID、广告位 ID 与任何密钥都必须由开发者在自己的本地项目中配置，不能提交到仓库。
